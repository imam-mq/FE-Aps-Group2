# FE-Aps-Group2

Frontend aplikasi pencatatan APS Group 2. Dibangun dengan React + Vite + Tailwind CSS + ke backend [BE-Aps-Group2](https://github.com/imam-mq/BE-Aps-Group2) api rest auth JWT.

## Demo

![Demo APS Group 2](assets/demo.gif)

## Fitur

- Login username & password (JWT)
- Tambah, edit, dan hapus data aplikasi (soft delete)
- Pencarian data berdasarkan nama aplikasi
- Pagination
- Notifikasi toast untuk setiap aksi (sukses/gagal)

## Tech Stack

- React
- Vite
- Tailwind CSS
- Fetch API
